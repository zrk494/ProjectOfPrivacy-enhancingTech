# Polymarket 异常检测可视化系统 (Visualize Sub-module)

本项目是隐私增强技术课程 (CS6290) 项目的 `Visualize` 子模块。本项目致力于为 Polymarket 预测市场数据提供交互式的可视化界面，并深度集成展示底层算法模块 (`Algorithm`) 检测出的市场异常和狙击手行为。

## 🌟 核心特性

- **市场数据洞察 (Market Insights)**：支持市场元数据的加载、时间序列数据展示以及交易量分布记录的可视化。
- **异常检测分析 (Detective Report)**：
  - **狙击手检测 (Type B - Sniper Detection)**：卡片式展示狙击手候选列表（基于 41 条严格筛选的候选数据，并深度解析 3 条已验证案例），集成攻击窗口交易图片 (`images/` 目录) 辅助分析。
  - **市场压力异常 (Type A - Market Stress)**：展示基于时间桶特征的市场压力事件及峰值压力分数图表，直观反映市场的宏观剧烈波动。
- **国际化支持 (i18n)**：内置多语言字典 (`config/language.py`)，支持中文与英文界面一键无缝切换。
- **高性能架构**：采用全局数据预热和优化的 Streamlit 缓存机制 (`@st.cache_data`)，确保在大规模数据回测下的页面级秒级响应。
- **模块化设计**：采用分层架构，代码结构清晰，易于维护和扩展。

## 🛠 技术栈

- **运行环境**：Python 3.10.11
- **核心框架**：Streamlit (Web 应用与交互逻辑)
- **数据处理**：Pandas
- **可视化库**：Plotly

## 🚀 快速启动

### 1. 环境准备

确保您的计算机已安装 Python 3.10.11。推荐使用虚拟环境：

```
python -m venv venv
source venv/bin/activate      # Linux/Mac
venv\Scripts\activate         # Windows
```

### 2. 安装依赖

```
pip install -r requirements.txt
```

### 3. 数据集准备

系统依赖两个主要数据源进行渲染，请确保数据放置在正确的路径下（路径计算逻辑见 `config/paths.py`）：

- **狙击手检测数据**：默认读取 `visualize/frontend_sniper_detection/`，需包含：
  - `stats/strict_sniper_candidates.csv`：41条严格狙击手候选数据
  - `stats/top10_suspicious_sessions.csv`：Top 10可疑会话
  - `detailed_cases.json`：3个已验证案例详情
  - `all_cases.json`：所有候选案例
  - `images/`：攻击窗口可视化图片

- **市场压力检测数据**：默认跨模块读取 `submodules/algorithm/CS6290-polymarket-anomaly-detection/results/` 下的：
  - `stress_events_enriched_{score_method}.csv`：丰富的压力事件数据
  - `bucket_features_*.csv`：时间桶特征数据
  - `bucket_scores_*.csv`：时间桶分数数据

### 4. 运行应用

Windows 用户可以直接双击运行 `start_app.bat`，或在终端执行：

```
streamlit run app.py
```

## 🔧 核心功能

### 1. 市场数据可视化
- **元数据展示**：显示市场基本信息和统计数据
- **时间序列分析**：展示交易量、价格等指标的时间变化趋势
- **交易数据透视**：分析交易分布和模式

### 2. 异常检测可视化

#### 2.1 市场压力异常检测（Type A - Market Stress）

采用**三层下钻式**可视化方案，帮助用户从宏观到微观逐步分析市场异常：

**第一层：全市场宏观概览**
- Top 压力事件排行榜：展示全市场最严重的异常事件
- 市场健康度对比：条形图展示各市场异常事件频率
- 快速识别高风险市场

**第二层：单市场事件汇总**
- 事件归因分布：饼图展示异常驱动因素（交易活跃度/流动性/价格偏移/混合）
- 事件气泡图：时间轴上的事件分布，气泡大小表示交易量
- 事件详情列表：展示事件的详细指标
- 支持选择特定事件进入第三层分析

**第三层：单事件微观诊断**
- 四个对齐的子图，共享时间轴：
  - 综合压力评分图：压力分数走势 + 异常阈值
  - 交易活跃度图：成交笔数（柱状图）+ 成交金额（折线图）
  - 流动性状态图：点差（折线图）+ 总深度（面积图）
  - 价格走势图：中位价（折线图）
- 使用半透明背景色块高亮事件区间
- 时间范围扩展：事件前后各 10 分钟

#### 2.2 狙击手检测（Type B - Sniper Detection）

采用**卡片式布局**展示狙击手检测结果，提供直观的视觉反馈：

**统计概览**
- 狙击手候选总数
- 平均异常分数
- 已验证案例数量

**分数分布分析**
- 直方图展示异常分数分布
- 横坐标：异常分数，纵坐标：频率

**已验证案例展示**
- 卡片式布局，每个案例独立展示
- 卡片内容：案例排名、会话ID、持续时间、异常分数、获利情况
- 支持展开查看详细信息：
  - 买入操作详情（金额、价格、时间、交易哈希）
  - 卖出操作详情（金额、价格、时间、交易哈希）
  - 攻击窗口可视化图片

**狙击手候选列表**
- 按可疑度排名排序
- 分页显示（每页 5 个候选）
- 风险等级颜色标识：
  - 🔴 高风险：红色（异常分数 < -0.6）
  - 🟡 中风险：橙色（-0.6 ≤ 异常分数 < -0.5）
  - 🟢 低风险：绿色（异常分数 ≥ -0.5）

### 3. 交互式分析
- **排序与筛选**：支持按时间、可疑度等维度排序
- **详情查看**：支持展开查看详细交易信息
- **分页浏览**：支持分页显示大量数据
- **多语言支持**：支持中英文界面切换

## 📖 使用指南

### 异常检测视图使用流程

#### 市场压力异常检测（三层下钻式）

1. **选择异常类型**：在异常检测页面选择"市场压力异常"
2. **第一层 - 宏观概览**：
   - 查看 Top 压力事件排行榜
   - 观察市场健康度对比图
   - 选择感兴趣的市场进入第二层
3. **第二层 - 事件汇总**：
   - 查看该市场的事件归因分布
   - 分析事件气泡图
   - 浏览事件详情列表
   - 选择特定事件进入第三层
4. **第三层 - 微观诊断**：
   - 查看四个对齐的子图
   - 分析压力分数、交易活跃度、流动性、价格的走势
   - 理解异常发生的具体原因

#### 狙击手检测（卡片式布局）

1. **选择异常类型**：在异常检测页面选择"狙击手检测"
2. **查看统计概览**：了解狙击手候选总数、平均异常分数、已验证案例数量
3. **分析分数分布**：观察异常分数的分布直方图
4. **查看已验证案例**：
   - 浏览已验证案例卡片
   - 点击"查看详情"展开详细信息
   - 查看攻击窗口可视化图片
5. **浏览候选列表**：
   - 按可疑度排名查看候选
   - 使用分页控件翻页
   - 根据风险等级颜色标识快速识别高风险候选

### 常见操作

- **切换语言**：在侧边栏选择语言（中文/英文）
- **选择市场**：在侧边栏选择要分析的市场
- **切换视图**：在主界面选择不同的视图类型（元数据/时间序列/交易/异常）
- **展开详情**：点击"查看详情"按钮展开详细信息
- **分页浏览**：使用上一页/下一页按钮翻页

## ❓ 常见问题解答

### Q1: 如何切换异常检测类型？
**A**: 在异常检测视图中，使用下拉选择器在"市场压力异常"和"狙击手检测"之间切换。

### Q2: 市场压力异常检测的三层视图如何使用？
**A**: 
- 第一层：查看全市场概览，选择感兴趣的市场
- 第二层：查看该市场的事件汇总，选择具体事件
- 第三层：查看该事件的详细诊断分析

### Q3: 狙击手检测的风险等级是如何划分的？
**A**: 基于异常分数（anomaly_score）划分：
- 高风险（红色）：异常分数 < -0.6
- 中风险（橙色）：-0.6 ≤ 异常分数 < -0.5
- 低风险（绿色）：异常分数 ≥ -0.5

### Q4: 如何查看狙击手攻击窗口的可视化图片？
**A**: 在已验证案例卡片中，点击"查看详情"按钮，展开后即可看到攻击窗口可视化图片。

### Q5: 数据加载失败怎么办？
**A**: 请检查以下内容：
1. 确认数据文件是否存在于正确的路径
2. 检查数据文件格式是否正确
3. 查看控制台错误信息，确认具体问题

### Q6: 为什么某些图表显示"No data available"？
**A**: 这可能是因为：
1. 对应的数据文件不存在
2. 数据文件为空
3. 数据格式不符合要求

### Q7: 如何提高页面加载速度？
**A**: 系统已内置以下优化：
- 数据缓存机制
- 分页显示
- 条件渲染
- 懒加载详情信息

### Q8: 支持哪些语言？
**A**: 目前支持中文和英文，可在侧边栏切换。

### Q9: 如何导出分析结果？
**A**: 目前版本暂不支持直接导出，但可以通过截图保存分析结果。

### Q10: 系统对数据有什么要求？
**A**: 
- 狙击手检测数据：需要包含 `strict_sniper_candidates.csv`、`detailed_cases.json`、`all_cases.json` 和 `images/` 目录
- 市场压力检测数据：需要包含 `stress_events_enriched_*.csv`、`bucket_features_*.csv`、`bucket_scores_*.csv` 等
