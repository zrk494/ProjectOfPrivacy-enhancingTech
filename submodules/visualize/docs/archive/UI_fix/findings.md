# 异常展示位置重构发现

## 当前实现分析

### 1. app.py 中的视图切换逻辑
- 当前视图切换通过 `view_type` 变量控制，包含四种视图：'metadata'、'timeseries'、'trade' 和 'anomaly'
- 所有视图在同一区域展示，通过条件判断决定显示哪个视图
- 异常视图与其他三个视图平级，没有特殊处理

### 2. ui_utils.py 中的侧边栏实现
- 侧边栏使用 radio 组件实现视图选择
- 视图选项包含：元数据视图、时间序列视图、交易视图和异常检测
- 异常检测选项硬编码为中文 "异常检测"，与其他多语言选项不一致
- 视图选择通过映射关系转换为内部 view_type 值

### 3. 异常展示视图的实现
- 异常展示视图由 `display_anomaly_view` 函数实现
- 位于 views 模块中，与其他三个视图函数平级
- 调用方式与其他视图一致，需要 selected_market_id 参数

## 重构方案

### 1. 侧边栏重构方案
- 将异常检测从主视图选择中分离
- 添加专门的异常视图切换按钮
- 保持原有三个视图的选择逻辑不变
- 实现双级导航：先选择普通视图类型，再选择是否进入异常视图

### 2. 主页面布局重构方案
- 主页面默认显示 metadata、timeseries、trade 三个视图
- 异常视图作为独立页面或独立区域展示
- 实现平滑的视图切换，保持用户体验一致性
- 确保异常视图的功能完整，与原有实现保持一致

## 国际化处理发现

### 1. anomaly_view.py 中的硬编码中文文本
- 发现多处硬编码的中文文本，如"页码"、"显示 X-Y 条，共 Z 条"等
- 这些文本需要替换为国际化变量
- 需要在 language.py 文件中添加对应的中英文对照表达

### 2. 国际化实现方式
- 参考了现有的多语言实现模式，使用 LANGUAGES[lang] 进行文本替换
- 确保所有新增文本都有对应的中英文对照
- 验证了修改后的文件在运行时能够正确加载和显示对应语言的文本内容

## 图片路径修复发现

### 1. 图片路径引用问题
- anomaly_view.py 中图片路径采用相对路径格式，如 "images/sniper_rank2_74seconds.png"
- 这些路径在不同环境下可能无法正确解析
- 实际图片资源的绝对路径为 "frontend_sniper_detection/images"

### 2. 路径修复方案
- 使用 Pathlib 计算正确的相对路径
- 从 anomaly_view.py 文件位置出发，向上两级到 visualize 目录，再进入 frontend_sniper_detection/images
- 确保路径解析不受操作系统差异影响
- 验证了所有修改后的相对路径在开发环境和部署环境中均能正确加载图片资源

## 分页UI优化发现

### 1. 当前分页实现问题
- trade_view.py 中使用 st.number_input 组件实现分页功能
- 这种实现方式用户体验不佳，需要手动输入页码
- 缺乏直观的上一页/下一页按钮
- 与整体界面设计风格不一致
- 分页起始页从0开始，不符合用户习惯

### 2. 分页优化方案
- 设计并实现更直观的分页控件，包含上一页/下一页按钮和页码显示
- 保持与整体界面设计风格的一致性
- 确保在不同浏览器和设备尺寸下都能正常显示
- 系统性检查项目中其他文件中实现类似翻页功能的UI组件情况
- 制定统一的优化标准和实施方案，进行同步修改

### 3. 分页起始页优化
- 将分页起始页从0改为1，符合用户习惯
- 确保所有分页组件的页码显示一致性
- 验证分页逻辑在起始页为1时的正确性
- 在 trade_view.py 和 anomaly_view.py 中统一实现
