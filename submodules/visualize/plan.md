# Sniper Detection 可视化方案

## 1. 方案概述

`display_anomaly_view` 函数通过卡片式布局和数据可视化，为用户提供了直观的狙击手检测结果展示。该方案采用分层设计，包括统计概览、分数分布分析、已验证案例展示和候选列表，全面呈现狙击手检测的关键信息。

## 2. 核心功能模块

### 2.1 异常检测类型选择
- 提供下拉选择器，允许用户在 "多市场异常" 和 "狙击手检测" 之间切换
- 当选择 "狙击手检测" 时，调用 `display_sniper_detection_cards` 函数

### 2.2 狙击手统计概览
- 显示三个关键指标：
  - 狙击手候选总数
  - 平均异常分数
  - 已验证案例数量
- 使用 Streamlit 指标卡片，直观展示统计数据

### 2.3 狙击手分数分布分析
- 使用 Plotly 直方图展示异常分数的分布情况
- 横坐标为异常分数，纵坐标为频率
- 提供视觉化的风险分布趋势

### 2.4 已验证案例展示
- 采用卡片式布局，每个案例显示为独立卡片
- 卡片包含：
  - 案例排名和会话ID
  - 攻击持续时间和异常分数
  - 获利情况（带颜色标识：绿色表示正利润，红色表示负利润）
- 支持展开查看详细信息：
  - 买入操作详情（金额、价格、时间、交易哈希）
  - 卖出操作详情（金额、价格、时间、交易哈希）
  - 攻击窗口可视化图片

### 2.5 狙击手候选列表
- 按可疑度排名排序，从高到低展示
- 实现分页功能，每页显示5个候选
- 每个候选卡片包含：
  - 会话ID和可疑度排名
  - 交易数量和总交易量
  - 异常分数（带风险等级颜色标识：
    - 高风险：红色（异常分数 < -0.6）
    - 中风险：橙色（-0.6 ≤ 异常分数 < -0.5）
    - 低风险：绿色（异常分数 ≥ -0.5）
  ）

## 3. 数据流程

1. **数据加载**：
   - 调用 `load_sniper_detection_data()` 加载狙击手候选数据
   - 调用 `load_sniper_detailed_cases()` 加载已验证案例数据

2. **数据处理**：
   - 检查数据是否为空，为空则显示警告信息
   - 对候选数据按可疑度排名排序
   - 计算分页参数

3. **数据展示**：
   - 显示统计概览
   - 生成并展示分数分布图表
   - 渲染已验证案例卡片
   - 渲染分页的候选列表卡片

## 4. 交互设计

### 4.1 分页控制
- 实现上一页/下一页按钮
- 显示当前页码和总页数
- 使用会话状态管理页码，确保页面切换时保持状态

### 4.2 详情展开
- 为已验证案例提供可展开的详情面板
- 点击 "查看详情" 展开按钮，显示详细交易信息

### 4.3 视觉反馈
- 根据异常分数和获利情况使用不同颜色标识
- 提供图片加载失败的警告信息

## 5. 技术实现要点

- **布局**：使用 Streamlit 的容器、列和卡片组件创建结构化布局
- **可视化**：使用 Plotly 生成直方图展示分数分布
- **状态管理**：使用 Streamlit 会话状态管理分页
- **响应式设计**：通过列布局和容器确保在不同屏幕尺寸下的良好显示
- **国际化**：使用 LANGUAGES 字典支持多语言显示

## 6. 数据源

- **狙击手候选数据**：从 `load_sniper_detection_data()` 加载，包含会话ID、交易数量、总交易量、异常分数等
- **已验证案例数据**：从 `load_sniper_detailed_cases()` 加载，包含排名、会话ID、交易详情、攻击窗口图片等
- **攻击窗口图片**：从 SNIPER_IMAGES_DIR 目录加载

## 7. 性能优化

- **分页显示**：通过分页机制减少一次加载和显示的数据量
- **条件渲染**：仅在数据存在时显示相应组件
- **懒加载**：仅在用户展开详情时显示详细信息

## 8. 扩展性

- 支持添加更多狙击手检测指标
- 可扩展为支持实时数据更新
- 可集成更多可视化图表类型
- 可添加筛选和搜索功能
